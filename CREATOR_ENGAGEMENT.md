## Posting Workflow

### Human-in-the-Loop Process
1. **Daily Scan**: System surfaces relevant creator posts
2. **Match**: Algorithm suggests character + comment template
3. **Review**: Human approves/edits comment
4. **Post**: Comment goes live with tracking
5. **Engage**: Monitor replies, escalate to human if needed

### Engagement Triggers
- Creator mentions: AI, surveillance, automation, deepfakes, etc.
- Viral tech controversy (>10k views on topic)
- News event matching a case in database
- Creator asks question in comments

### Response Time Targets
- Breaking news: 2-4 hours (character hot takes)
- Relevant content: Same day
- Evergreen topics: Within 48 hours

- Comment engagement rate (likes, replies)
- Profile clicks from comments
- Site visits from social referrers
